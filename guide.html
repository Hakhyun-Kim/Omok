Premium Omok

모바일 터치 스크린과 고사양 웹 환경에 최적화된 하이브리드 2D/3D 오목 웹 게임 설명서

HTML5 Canvas Vanilla CSS Vanilla JS (ES6) Three.js (3D Rendering) Web Audio API Synthesizer
게임 플레이하기 GitHub 저장소

오목의 새로운 차원, 주요 기능 안내

Premium Omok은 일반적인 바둑판 게임을 현대적인 감각과 고급 사운드 기술로 업그레이드한 고품격 웹 앱입니다.

드래그 조준 & 스냅 (Pointer Snapping)

손가락 터치 시 누르는 지점이 가려지는 터치 노트북/모바일 특유의 문제를 완전히 해결했습니다. 화면을 터치하여 손가락을 끌면 가장 가까운 눈금선 교차점에 빛나는 링(Snap Ring)이 투영되어 표시됩니다. 손가락을 떼는 순간 정확히 착수되어 실수 없는 완벽한 조종이 가능합니다.

2D / 3D 실시간 뷰 전환

언제든 하단 컨트롤러의 3D 모드 / 2D 모드 버튼을 누르면 실시간으로 대국 테마가 전환됩니다. Three.js 물리 렌더링에 기반한 입체적인 3D 돌과 입체 바둑판을 원하는 시점과 각도로 자유롭게 바라보며 깊은 몰입감을 느낄 수 있습니다.

실시간 소리 합성 (Web Audio API)

사운드 파일의 누락이나 로딩 지연을 방지하기 위해 브라우저 자체 오실레이터를 이용하여 돌을 놓는 소리를 실시간으로 합성(Procedural Synth)합니다. 묵직하고 밀도감 있는 흑돌 타격음과 맑게 공명하는 백돌 조개 울림을 완벽하게 재현했습니다.

30초 생각 시간 & 긴장감 연출

턴마다 30초의 생각 시간이 주어지며, 게이지와 타이머 수치로 줄어드는 시간이 투영됩니다. 5초 이하로 접어들면 게이지 바가 긴박한 네온 레드로 반짝이며 초당 경고 비프음이 발생합니다. 특히 남은 2초 동안은 더 날카로운 고음역 경보가 구동됩니다.

게임 규칙 및 조작 가이드

🏆 기본 규칙

  • 오목 규칙: 흑돌과 백돌이 교대로 착수하며, 가로/세로/대각선 방향 중 어느 쪽이든 먼저 자신의 돌 5개를 일렬로 놓으면 승리합니다.
  • 전적 기록: 승리 시 로컬 브라우저 저장소(LocalStorage)에 전적이 영구 보존되어 매 대국 승수가 자동으로 누적됩니다.

🛡️ 선공 베네핏 (Black Starting Advantage)

흑돌(선공)의 압도적인 유리함을 보완하거나 게임의 재미를 위해 첫 턴에 연이어 착수할 수 있는 베네핏 기능을 탑재하고 있습니다.

  • 베네핏 설정(0~3): 기본 오목(0) 외에 1~3개의 추가 착수를 첫 턴에 허용합니다. (예: 베네핏 2 설정 시 첫 턴에 흑돌이 연이어 3수 착수 가능)
  • 첫 턴에 설정된 돌을 모두 배치하는 즉시 백돌의 차례로 부드럽게 턴이 전환됩니다.

사용자 컨트롤 인터페이스

🖱️ 2D 모드 조작

  • 조준 후 착수: 화면을 클릭(또는 터치)한 상태로 부드럽게 드래그하여 원하는 교차점에 조준 링이 위치하도록 조정한 뒤, 클릭을 놓으면 착수됩니다.
  • 즉시 착수: 빈 격자 자리를 탭하거나 마우스로 가볍게 클릭해도 즉각적으로 착수할 수 있습니다.

🔮 3D 모드 카메라 조작 (OrbitControls)

기능 마우스 조작 터치스크린 조작
회전 (Orbit) 마우스 좌클릭 후 드래그 한 손가락 드래그
화면 이동 (Pan) 마우스 우클릭 (또는 Ctrl+좌클릭) 후 드래그 두 손가락 쓸어넘기기
줌 인/아웃 (Zoom) 마우스 휠 스크롤 두 손가락 핀치(Pinch) 줌

내 컴퓨터에서 바로 실행하기 (How to Run & Deploy)

방법 A. 윈도우 런처 이용 (원클릭)

별도의 설정이나 터미널 실행 없이 바로 게임을 켜고 싶을 때 가장 유용한 방법입니다.

  1. GitHub 혹은 다운로드한 폴더 내의 play.bat 파일을 더블 클릭하여 실행합니다.
  2. 시스템 기본 브라우저가 열리며 쾌적하게 오목을 즉각 시작할 수 있습니다.

방법 B. 로컬 웹 서버 실행 (서버 환경 테스트)

보안 사유로 웹 사운드(Web Audio API) 오디오 컨텍스트가 구글 크롬 등 로컬 파일 프로토콜(file://) 하에서 일부 제한될 경우 사용하는 개발자용 가이드입니다.

  1. 터미널(Cmd / PowerShell 등)을 실행하여 오목 폴더로 이동합니다.
  2. 아래의 Node.js 원패스 서버 구동 명령을 작성합니다.
    npx -y http-server . -o
  3. 서버 구동과 동시에 브라우저가 실행되며 `http://localhost:8080` 포트로 완벽한 사운드와 함께 실행됩니다.
오디오 자동재생 보안 정책 안내

브라우저 보안상 첫 사용자 인터랙션(보드 클릭 등)이 발생하기 전까지는 Web Audio API의 소리가 들리지 않도록 재생 차단(Autoplay Block)이 걸려있습니다. 바둑판에 첫 돌을 놓거나 화면을 한 번 이상 터치하시면 정상적으로 사운드가 들립니다.
